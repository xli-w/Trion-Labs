# Prompts

This folder contains AI prompts used to guide product, feature, and review work in the Trion Labs repo.

## Recommended structure

- Product and experience prompts for the active Trion experience
- Feature delivery prompts for individual improvements
- Review prompts for quality, accessibility, and final sign-off
- Archive-related prompts only when referencing historical work

## Current scope

The repo is primarily oriented around the active experience in [../experiences/trion-operations-experience](../experiences/trion-operations-experience). Historical work remains in [../archive](../archive).
